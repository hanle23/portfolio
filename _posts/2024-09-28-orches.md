A music-focused web app built with Next.js / TypeScript. Orches explored playlist workflows, track similarity, and interactive browsing of saved music data.

The project reached a v1 release and shipped with a live demo. The repository is now archived, but it remains a solid product-shaped piece of work from that period.

**Stack:** TypeScript, Next.js  
**Status:** Archived
