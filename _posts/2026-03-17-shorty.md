A CLI tool for managing and running command shortcuts and reusable shell scripts.

Shorty lets you define aliases for frequently used commands and organize scripts by name. When a name matches both a shortcut and a script, the shortcut wins — use `shorty script <name>` to run the script explicitly.

**Stack:** Go  
**Platforms:** macOS, Linux  

```sh
go install github.com/hanle23/shorty@latest
shorty init
shorty <name> [args...]
```
