A Java desktop system for exploring World Bank demographic and economic data.

It retrieves data for one or more countries, runs configurable analyses, and renders results with bar charts, line graphs, scatter plots, and pie charts.

**Stack:** Java, Maven  

```bash
mvn clean install
java -jar target/WorldBankVisualization.jar
```
